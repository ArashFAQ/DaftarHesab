# دفتر حساب

اپ اندرویدی ثبت بدهی و پرداخت مشتری‌ها، با بکاپ خودکار روی Supabase بعد از هر تغییر.

- ساخت APK: هر push روی `main` یک Release جدید می‌سازد (دکمه‌ی به‌روزرسانی داخل اپ از همین‌جا نسخه‌ی جدید را می‌گیرد).
- شاخه‌ی `dev` فقط بیلد آزمایشی است و منتشر نمی‌شود.
- جدول‌های Supabase: `supabase/schema.sql`
